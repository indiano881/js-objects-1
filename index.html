JavaScript Objects - Exercises

Write your code in exercises.js. Open the browser console to see your results.

Part 1: Object Basics

Exercise 1: Create an object called favouriteMovie with the following properties: title, year, rating, and watched. Choose your own values.

Exercise 2: Console log the title and year of your movie using dot notation. Then console log the rating using bracket notation.

Exercise 3: Change the rating to 9. Add a new property called runtime. Delete the watched property. Console log the updated object.

Exercise 4: Create a variable called key containing the string "title". Use bracket notation to access the movie title. Change the variable to "year" and try again.

Question: Why doesn't favouriteMovie.key work?

Part 2: Nested Objects and Arrays

Exercise 5: Add a director property containing an object with a name and country. Console log the director's name.

Exercise 6: Add a genres property containing an array of three genres. Console log the second genre.

Exercise 7: Add a cast property containing an array of two actor objects. Each actor should have a name and role. Console log the role of the first actor.

Part 3: Looping Through Objects

Exercise 8: Use a for...in loop to console log every property name and its value from favouriteMovie.

Exercise 9: Use Object.keys() to console log all property names. Then console log the total number of properties.

Exercise 10: Use Object.values() to get all values from your movie object. Loop through the returned array and console log each value.

Exercise 11: Use Object.entries() to console log each key and value.

Part 4: Value vs Reference

Exercise 12: Create two different objects containing exactly the same properties and values. Compare them using ===. What is the result? Why?

Exercise 13: Create a new variable and assign favouriteMovie to it. Change the title using the new variable. Console log both variables. What happened?

Exercise 14: Create two variables containing the same number. Change one of them. Compare this behaviour with Exercise 13.

Part 5: Bonus - Arrays and DOM

Exercise 15: Create an array called movies containing three movie objects. Use forEach() to console log the title of every movie.

Exercise 16: Use filter() to create a new array containing only movies released before the year 2000. Console log the result.

Exercise 17: Create a paragraph for each movie and append it to the div below. Display the title and year of each movie.

Exercise 18: Create a button for each movie. When a button is clicked, display that movie's title and rating in the div below.
