Objects - Exercises

Write your code in js/exercises.js and open the console to see the results.

Part 1: one object (favouriteMovie)

Exercise 1: Console log the title and the year of favouriteMovie like this: "Back to the Future - 1985".

Exercise 2: Console log the name of the director, the second genre, and the role of the first actor in the cast.

Exercise 3: Console log the whole object. Then change the rating to 9, add a property runtime with the value 116, and delete the watched property. Console log the object again and compare.

Exercise 4: Create a variable key with the value "rating". Use it to console log the rating of favouriteMovie. Then change key to "year" and log again. Why doesn't favouriteMovie.key work?

Exercise 5: Use a for...in loop to console log every property of favouriteMovie like this: "title: Back to the Future". What happens with director? Why?

Extra: console log how many properties the object has, using Object.keys().

Exercise 6 (this): Add a method describe to favouriteMovie that returns "Back to the Future (1985), directed by Robert Zemeckis, rated 9". Use this, don't type the values!

Then add a method rate(newRating) that changes the rating of the object and console logs the new description.

Extra: write describe again as an arrow function. What happens? Write a comment explaining why.

Part 2: array of objects (movies)

Exercise 7: Console log the title of every movie (use forEach).

Exercise 8: Console log title and year of only the movies released before 2000.

Exercise 9: Count how many movies you haven't watched yet, and push their titles into a new array called toWatch. Console log both.

Exercise 10: Calculate the average rating of all movies (round it to 2 decimals with toFixed(2)). Then find the movie with the highest rating using a loop and console log its title and rating.

Exercise 11: Console log the title of every movie that has "Sci-Fi" in its genres. (Hint: array.includes())

Exercise 12: Console log EVERY actor of EVERY movie like this: "Keanu Reeves plays Neo in The Matrix". (Hint: a loop inside a loop)

Extra: console log all the movies directed by Christopher Nolan.

Exercise 13:

  1. Push a new movie object of your choice into movies (with ALL the same properties, id 9).
  2. Write a function markAsWatched(id) that loops over the movies and sets watched to true for the movie with that id. Test it with id 2.
  3. Make a copy of the first movie with the spread operator and change the copy's title. Console log both to show the original did not change.

Part 3: DOM

Exercise 14: Add a paragraph to this div for each movie, like "Inception (2010) - 8.8". Watched movies should end with " ✔".

Exercise 15: Create one button for every movie (with the movie title as text) inside #exercise15-buttons. When a button is clicked, show the director and the cast of that movie inside #exercise15-details (replace the old details on each click).

Bonus

Bonus: Create an object that counts how many movies come from each director's country, like { UK: 2, Japan: 1, ... }. Console log it. (Hint: bracket notation with a variable key, and check if the key already exists.)
