# JS Objects - lesson 1 (movies)

Open `index.html` / `exercises.html` in the browser and keep the console open.

| File | What it is |
| --- | --- |
| `index.html` + `js/lesson.js` | Live-coding lesson: `lesson.js` has only comments with the timed steps (~90 min) |
| `exercises.html` + `js/exercises.js` | 15 exercises + a bonus. Instructions are in the HTML, write the code in the JS |
| `styles/style.css` | Shared styles |

## Lesson outline
1. Why objects · 2. Object literals · 3. Dot / bracket notation · 4. Update / add / delete
5. **Your turn #1** · 6. Nested data · 7. Arrays of objects · 8. **Your turn #2**
9. `for...in`, `Object.keys/values/entries` · 10. Methods & `this` · 11. Reference vs copy (spread) · 12. Recap

For a 60 min version, skip `Object.keys/values/entries` (step 9) and step 11.

## Exercises
- Part 1 (1-6): one object: access, change, variable keys, `for...in`, methods + `this`
- Part 2 (7-13): array of objects: filtering with `if`, counting, averages, max, `includes`, nested loops, spread copy
- Part 3 (14-15): render to the DOM + click events
- Bonus: an object used as a counter
